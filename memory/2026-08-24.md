- **Rejoin Bug Fix (2026-08-24):**
  - Issue: After a member was removed from WhatsApp and then rejoined, the dashboard showed "Duplicate join" and the sheet's Joining/Expire dates were not updated.
  - Root cause: `handleJoin()` in `src/server.js` treated any existing row with the same phone as a duplicate, regardless of status (`REMOVED` / `EXPIRED`).
  - Fix: `handleJoin()` now checks the member's state. If state is `REMOVED` or `EXPIRED`, it calls `sheets.updateMember({ phone, joining, expire })` to update the existing row with fresh `Joining` + `Expire` (7 days) and logs `member_rejoined`. If state is `PERMANENT` or `ACTIVE`, it logs `duplicate_join` and does nothing.
